# 👤 Interactive Employee Profile App

A simple Streamlit app showcasing an employee's profile — including skills, work experience, education, and a contact form — navigable through a sidebar menu.

## Features
- Sidebar navigation across About, Skills, Experience, Education, and Contact sections
- Skill proficiency levels shown with progress bars and a bar chart
- Expandable work experience timeline
- Contact form with input validation
